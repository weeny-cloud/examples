# Weeny examples

Small, runnable app starters for [Weeny](https://weeny.cloud/), with persistent data and local development instructions.

The initial collection is being prepared in a pull request: Node.js + SQLite, React + FastAPI, and Streamlit.

See [deployment recipes](https://weeny.cloud/recipes) and [free hosting details](https://weeny.cloud/free).
